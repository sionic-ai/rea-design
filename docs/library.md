## About the rebuilds

Each library site is an original rebuild, written from scratch to study the layout, proportions and motion of a public website. No text, images, logos, video or source code from those sites is included: copy is English placeholder text, pictures and videos are generated placeholders, and names and domains are removed. Use it as a reference for structure and motion and bring your own content.

If you spot a page that still carries an identifying trace, [open an issue](https://github.com/sionic-ai/rea-design/issues/new?template=brand-trace.yml).

Third-party licenses (GSAP's Standard License, Fontshare fonts, vendored libraries) are listed in [NOTICE.md](../NOTICE.md).
